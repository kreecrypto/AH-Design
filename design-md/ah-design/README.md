# AH Design — Single DESIGN.md

**Design language:** Enterprise UI, deep blue `#00008F`, light-blue operational canvas `#F0F6FF`, white cards, DB Helvethaica X web-first, measured desktop app shell and compact data tables.

This directory contains **one design system only**.

| File | What it is |
|---|---|
| [`DESIGN.md`](DESIGN.md) | Full AH Design v2.6 specification; identical to the canonical root and `docs/` copy |
| [`preview.html`](preview.html) | Single-file visual catalog. Download and open locally |
| [Repository README](../../README.md) | Copy-and-paste instructions for coding agents |

**Use:** copy `DESIGN.md` into your project root and instruct your coding agent to apply it; default to privacy-safe skeletons. Do not invent business labels, routes, status values or design tokens. Apply Home-only variants only to the documented Home reference.

The preview deliberately uses neutral specimen labels, tokens and geometric placeholders; it is not a client-facing product mockup. The repository stays private until its owner explicitly chooses otherwise.
